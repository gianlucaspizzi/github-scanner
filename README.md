# GitHub Scanner 🔍

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gianlucaspizzi/github-scanner.git
cd github-scanner
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the server

```bash
npm start
```

The server will run locally on port **4000** (http://localhost:4000).

---

## 🔥 Using the Application

- Open the `index.html` file in your preferred browser.
- Enter a GitHub access token.
- Click the button to scan repositories.
- View details for each repo including:
  - Repo name
  - Repo size
  - Repo owner
  - Private/public status
  - Number of files in the repo
  - Content of one YAML file (if any)
  - Active webhooks
